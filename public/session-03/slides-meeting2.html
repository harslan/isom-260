The framework · on your cheat sheet

Five ingredients: CRAFT.

C
CONTEXT — what does the model need to know?
R
ROLE — whose expertise should it borrow?
A
ACTION — what exactly should it do?
F
FORMAT — what shape should the answer take?
T
TONE — how should it sound?

Vague in → vague out. This is how professionals get reliable output on the first try.

While you build · the knobs

When the output isn't right, turn ONE knob.

Too generic → sharpen CONTEXT add the real details
Wrong expertise or attitude → change ROLE
Did the wrong thing → tighten ACTION one task, stated exactly
Right content, wrong shape → dictate FORMAT
Sounds off → ban specific phrases in TONE "we apologize for any inconvenience" is banned

One knob at a time — that's how you learn which ingredient does what.
