The agent loop · ~40 lines of Python

How the model reaches for a tool.

1
You send the message plus the tools' job descriptions — name, what it does, what inputs it takes
2
The model thinks: do I need a tool? If not, it just answers
3
If yes, it names the tool and the inputs. Your code runs it and sends the result back
4
Repeat until it has enough to answer. Then it answers.
A tool is just a Python function
A tool description is a job description
The loop is the whole trick

Same loop inside NanoClaw, OpenClaw, Claude Code, Gemini's agents. Today you watch it run on your pitch. Wednesday you write these 40 lines yourself.

The lesson under the lesson
