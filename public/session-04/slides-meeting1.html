The shift

A chatbot answers. An agent does.

Chatbot: "What's our revenue?" → "I don't have access to that data." one shot, then silence
Agent: queries the database → calculates growth → compares to forecast → "$2.3M, up 12%, 3% above plan" it reached for tools you gave it

The only new idea today the model can ask YOUR code to run a function — and use the result
The agent loop · ~40 lines of Python

How the model reaches for a tool.

1
You send the message plus the tools' job descriptions — name, what it does, what inputs it takes
2
The model thinks: do I need a tool? If not, it just answers
3
If yes, it names the tool and the inputs. Your code runs it and sends the result back
4
Repeat until it has enough to answer. Then it answers.
A tool is just a Python function
A tool description is a job description
The loop is the whole trick

Same loop inside NanoClaw, OpenClaw, Claude Code, Gemini's agents. You'll read it today, line by line.

Part 5 · together · 10 min

Your agent works. It would also get you fired.

The API rate-limits you toy: crash with 429 · production: wait and retry with backoff
A tool throws an error toy: crash · production: hand the error to the model, which reports it honestly
The model loops forever toy: burns money · production: a circuit breaker — max steps
The agent wants to send an email or issue a refund toy: just does it · production: an approval gate — a human says yes
"What did the AI do last Tuesday?" toy: nobody knows · production: an audit log of every tool call

The loop is 40 lines. The trust layer around it is the product.

AI for BUSINESS

What you can now say in a meeting.

"Should we build a chatbot or an agent?" does the task need to DO things, or just answer? That decides it
"What tools should it have?" a business decision, not an engineering one: which data, which actions
"How do we keep it from doing something stupid?" approval gates on actions, a step limit, an audit log — day one, not after the incident
"Why did the vendor's agent hallucinate a refund?" no error propagation: the tool failed and the model filled the gap
