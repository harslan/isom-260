The pattern gap

Three ways to split.

→
Pipeline
Researcher → writer → critic → 🚦. The handoff is a document, not a whisper. Each part sees only what it needs.
⑂
Router
One cheap call decides who handles it. A thank-you note never reaches the pipeline. Session 6's routing, in code.
✓
Critic
A checker that never writes, so it has nothing to defend. One call. The cheapest second agent there is.

The org chart you already know: someone reads, someone decides, someone signs, someone checks. Same names on every box = one agent.

The only honest rule

Name the reason.

Permissions one part may only read; another may act. The reader never holds the send button
Specialization a checker that never writes the thing it checks
Isolation whoever reads untrusted text — emails, pages, documents — must not hold the keys
Parallelism ten things at once. Rare in this course, common at scale

Can't write the sentence? One agent. That is a good answer, and most midterms are right to give it.
