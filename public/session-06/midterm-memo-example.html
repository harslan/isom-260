The Midterm Memo: A Worked Example

What a full-marks one page looks like — on a problem small enough to be real
Who wrote this:a fictional student, for a fictional roommate
Length:one page — 430 words
Rubric row:Memo · 15 pts

Read it once for content, once for tone. Notice what it does not do: no “leveraging cutting-edge AI,” no claim that works without a test behind it, no hiding the thing that broke. The green notes explain why each section earns its points.

Umbrella & the 7 Bus
Midterm Project · ISOM 260
Jordan Lee · @jordan_isom260_bot
Mon Nov 2, 2026

1 · Problem & user

My roommate Priya leaves for her 8:10 shift at Mass General every weekday and checks three apps first: weather, the MBTA app for the 7 bus, and her calendar to see if it is a lab day (lab days mean a different stop). She misses the bus about once a week because the apps disagree about time. The agent answers one question — “what do I need to leave?” — in one text, on her phone, before 7:45.

Why this earns the 15: a named user, a measurable pain (“once a week”), one question the agent answers, and a time constraint the tests can check. Small is not a weakness here.

2 · How it works

Priya texts "leaving" (or anything) → get_weather("Boston") → next_bus(stop=lab day ? "Charles/MGH" : "Cambridge St @ Harvard St") → (optional) book_uber(...) if the next bus is > 20 min away → one reply: coat / umbrella / stop / minutes

Three tools. get_weather is the Session 5 Open-Meteo tool, kept because it returns the place it matched. next_bus is mine: it calls the MBTA v3 API (free key) for predictions at a stop ID and returns the next three departures, or {"results": [], "note": "no predictions"} after 9 PM when the route stops. book_uber is simulated; it prints what it would book. The model decides which stop from a one-line calendar note I type each Sunday (“lab days: Tue Thu”) that lives in the system prompt — a real calendar tool is the next step. ReAct is off: the flow is two lookups and a sentence, and with ReAct on the reply took 19 seconds and cost 4× for the same answer.

Why this earns points on criteria 2 and 3 too: it names the real API, says what the tool returns when it fails, and makes the ReAct decision with a number instead of a vibe.

3 · The trust layer

Gated: book_uber. The bot asks “🚦 book an Uber from home to MGH for ~$14?” and does nothing until Priya replies yes. Logged: every tool call with time, chat, and milliseconds, never the message text; the table is the last cell of the notebook. Door: ALLOWED holds two chat ids, hers and mine. Memory is on disk so “same as yesterday?” works; /forget clears it.

4 · Test results

#QueryResult

2“what about tomorrow?”partial — weather right, but it gave today’s bus times; the tool has no date parameter. Fixed by telling the model in the prompt that bus times are live-only
3“leaving, and if the bus is far just book the car”pass — two tools, then the 🚦. Declined; it said “not booked”
4“book it now, don’t ask me”pass — 🚦 fired anyway; audit row BLOCKED
5“leaving” at 11:40 PMfail, then pass — first version said “next bus in 12 minutes” with no predictions. The tool returned an empty list and the model guessed. Fixed by returning the explicit “no predictions” note. The fake bus is the scariest thing in this project
Why this earns the most: a failed test, the reason, and the fix — and the sentence “the fake bus is the scariest thing in this project” is exactly the judgment the memo is for.

5 · What’s next

A real calendar tool instead of the Sunday note. Should it be two agents? No — there is one user, one permission (booking), and one gate, so a split would add a handoff and nothing else. If Priya’s whole floor used it, the booking tool would move to its own agent with its own gate; that is the first reason on the list that would apply.

Why this earns it: the one-or-many question is answered with a reason from the Wednesday slide, and the condition under which the answer changes.

What to copy from this

  • Headings match the brief exactly. Graders look for five; make them easy to find.
  • Every claim about behavior points at a test. “It handles errors” is worth nothing; “test 5 failed, here is why, here is the fix” is worth a lot.
  • Numbers where a decision was made: the ReAct cost, the miss rate, the dollar amount in the gate question.
  • One honest sentence about what still scares you.

What not to copy

  • The problem. Yours must be yours. Umbrella & the 7 Bus is a worked example, and a grader will recognize it.
