The OpenCode lab in one breath

  • Students: isom-260.vercel.app/session-11/opencode.html. Download the desktop app, download one zip (marco-monday-report: sales.csv, MISSION.md, AGENTS.md), open the folder in OpenCode
  • Model: DeepSeek V4.1 Flash Free. OpenCode's docs say its provider keeps nothing and doesn't train on it. Other free models may keep what's typed: practice data only, first names only
  • Mission 1: the agent builds report.html from sales.csv. The lab page has a rubric with checkboxes that gives a pass or fail, for Round 1 and Round 2
  • Round 2: one sentence in AGENTS.md (the agent's job description), save, new session, then "Rebuild report.html from sales.csv". The page shows Round 1 → Round 2 and whether anything broke
  • Mission 2: they type who it's for, what it is, 3 musts and 1 must not. The page writes the mission and turns their rubric into checkboxes. The agent builds gift.html
  • Plan B on the same page: a class-pass config (opencode.json) that runs OpenCode on the Sandbox with Gemini 2.5 Flash

  • A laptop can't install (Chromebook, iPad, locked laptop) → pair up. One working laptop per pair is the plan anyway
  • "Free usage limit" or free models blocked on the campus network → Plan B, class pass. If your own test this morning showed Plan B works, say "everyone, Plan B" early

  • Every report passes → good, say "now you know. Before, you only hoped." Then put Report B on the big screen: "this one looks better than yours. Grade it."
  • Nothing works at all → the Session 11 page still has 🧪 The Exam notebook (Colab, class pass). Run Parts 1–4 in class as originally planned
  • It never asks permission → normal. OpenCode's default is "allowed". Ask the room: "who set that badge?" If it does ask: read it, then allow it

  • It says Pad Thai → perfect. Put that one on the big screen
