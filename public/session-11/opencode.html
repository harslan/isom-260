ISOM 260 · Session 11 · optional · for your final project

A real coding agent, on your class pass.

OpenCode is an open-source coding agent, built like Claude Code. It runs in your terminal, reads your files, runs commands and writes files. Anyone can read its code. Here it runs on your class pass: no credit card, no personal key, and the Sandbox doesn't store what you type.

1 Install it (once)

If your laptop has Node.js, one line works on Mac and Windows:

npm install -g opencode-ai

No Node.js? Install it from nodejs.org (the LTS button) first, or see opencode.ai for other ways to install.

2 Make your project folder

Type your class pass. This page builds your config file. Nothing you type leaves this page.

Make a new folder, like my-agent. Put both files in it. Your pass sits inside opencode.json, so don't share that file.

See the config file

  


  

    
3 Start it inside that folder

    
cd my-agent
opencode

    
Then type a task in plain English. Try this one:

    
Read sales.csv. Which dish made the most money this week, and which day was busiest? Write a 5-line summary for Marco in summary.md with the numbers.

    
Watch it work: it reads the file, does the math, and writes summary.md. It may ask before running a command. Read what it wants to do, then say yes.

  


  

    
4 Now grade it. You know how.

    
Open summary.md. Today you learned that an answer that sounds right isn't a test. Here is the rubric:

    

      
✔ mustname Ramen as the dish with the most money this week, with the number

      
✔ mustname Saturday as the busiest day, with the number

      
✘ must notname Pad Thai as the top dish

    

    
Why would anyone say Pad Thai? The single biggest row in the file is Pad Thai on Saturday. An agent that grabs the top row gets it wrong. That's a 🌀 tricky test case: everyday input with a trap inside. Run it three times. Did it pass every time?

  


  

    
Good to know. Each step the agent takes is one call on your class pass, so a small task is about 4 to 10 calls and counts toward your daily limit. If you hit a limit, the message tells you when it resets. Keep personal data out of your prompts, same as always.
