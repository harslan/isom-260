🛠️ Put a real agent to work.

OpenCode is an open-source coding agent, built like Claude Code and used by millions of developers. It reads your files, writes code, runs it, and builds things. Two missions today. In both, your real job is the same: grade what it builds.

1 Get the app start the download now · we use it at 1:00

⬇ Download OpenCode Desktop
  • Mac: Apple Silicon for M1, M2, M3 or M4 Macs, Intel for older ones (Apple menu → About This Mac). Open the file and drag OpenCode into Applications.
  • Windows: x64 for most laptops. Run the installer. If Windows warns you, choose More info → Run anyway.
  • It's free. No account needed.

2 Get Marco's folder

⬇ marco-monday-report.zip
  1. Unzip it (double-click on Mac; on Windows, right-click → Extract All). You get a folder with sales.csv, MISSION.md and AGENTS.md.
  2. Open OpenCode and open that folder as your project.
  3. Pick a model: DeepSeek V4.1 Flash Free. It's free, and its provider doesn't keep or train on what you type. Free models come and go: if it's not there, pick another one with "Free" in its name, and keep personal data out.
Free models not working? Plan B: run it on your class pass

Type your class pass. This builds an opencode.json file. Nothing you type leaves this page. Put the file inside Marco's folder, reopen the folder in OpenCode, and pick Gemini 2.5 Flash (class pass).

Your pass is inside that file, so don't share it. Each step the agent takes is one call on your class pass.

3 Mission 1 · Marco's Monday Report 10 min

Marco runs North End Noodle Co. Every Monday he wants to know how last week went. Copy this into OpenCode and press Enter. Then watch it work: what does it read? What does it run? What does it write?

Read sales.csv. Build Marco a one-page report as report.html: the total for the week, money by dish, money by day, one simple bar chart, and three things he should do next week. Keep it clean and easy to read. When you're done, tell me how to open it.

If it asks permission to run a command or write a file, read what it wants to do first, then allow it. That's your badge from Session 9: some things it does alone, some things it asks a person.

Open report.html in your browser (double-click it in the folder).

4 Grade it you're the professor

It looks great. That's a vibe check. Now check it against the rubric, with sales.csv open next to it.

Tick what's true for your report.
Why would anyone say Pad Thai? (open after grading)

Pad Thai on Saturday is the single biggest line in the file: $1,216. But over the whole week, Ramen made more: $5,364 vs. $5,073. An agent that eyeballs the file instead of adding it up picks Pad Thai. That's a 🌀 tricky test case: everyday input with a trap inside.

5 Round 2: change one thing 5 min

Open AGENTS.md in the folder. It's the agent's job description: OpenCode reads it every time. Write one sentence under the line. Ideas:

"Compute every number with code from sales.csv. Never estimate."
"At the bottom, show the table you computed, so Marco can check it."
"Write for a busy owner: short sentences, the most important number first."
"Use navy and gold, like a Suffolk report."

Then type: Rebuild report.html. Grade it again on the Round 2 tab. What got better? Did anything break? That's a regression.
